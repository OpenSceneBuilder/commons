# The OSB commons

Welcome to Open Scene Builder. This is our public entrance and shared working notebook: why the work matters, how to get involved, and what needs building next.

Our aim is to make tools for the built environment that people can understand, extend and use while retaining control of their work.

## The workshops

The organization will hold both public and private project repositories. Public projects will be listed here when their maintainers, setup instructions and contribution terms are ready. Private work is shared only with the people assigned to it.

There are no public software releases in this new organization yet. The commons is the first working part of the home.

## Work with us

Open an issue using **Start a contribution** with the question you want to investigate and the experience you bring. Before implementation, agree the scope, inputs, expected evidence and reviewer.

A useful first contribution can be a critique, a diagram, a synthetic test case, a setup correction or a focused code change. People should be able to make a meaningful contribution without first understanding the whole system.
