# Questions worth bringing into the workshop

These are starting points for discussion, not claims of completed products.

## Model meaning across tools

Choose a small synthetic model and identify which geometry, identity or relationships must survive an exchange. What would prove that the result still means the same thing?

Useful first output: a compact example and an acceptance checklist, including one deliberate failure.

## Collaboration with data custody

Consider an author working locally, explicitly publishing selected work, and receiving a delivery receipt. Which additional evidence is needed before the shared project can treat that work as accepted and recoverable?

Useful first output: a short failure scenario that distinguishes delivery, approval and durable acceptance. No private repository access is required.

## A welcoming first hour

Read the public OSB entrance as a new contributor. What is unclear about the purpose, current maturity, access or next step?

Useful first output: a proposed correction and a short record of where a new contributor would get stuck.

For each proposal, agree scope and a reviewer before expanding it into implementation.
